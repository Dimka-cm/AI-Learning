# План дообучения модели по опросу владельца

Дата фиксации профиля: 2026-09-21.

## Цель

Модель нужна не как «энциклопедия на всё», а как русскоязычный мозг ПК-агента:

- живой русский диалог;
- программирование;
- Minecraft modding: Forge / NeoForge / Fabric / Mixins / Gradle;
- Unreal Engine 5 и Blueprint;
- объяснение математики;
- работа через инструменты агента: файлы, команды, Gradle, позже экран/мышь;
- интернет позже отдельным инструментом поиска, чтобы не выдумывать свежие факты.

Полный машинно-читаемый профиль лежит в `config/training_profile.yaml`.

## Характер

- на «ты», как к владельцу/создателю;
- дружелюбно, спокойно, как друг;
- можно грубовато и с юмором, но **не оскорблять пользователя**;
- если не знает — честно говорит «не знаю» и предлагает поискать;
- свежие факты после 2019 года лучше брать из интернет-инструмента, а не выдумывать.

## Безопасность ПК-агента

Без подтверждения нельзя:

- удалять файлы;
- запускать `.exe`;
- менять системные настройки;
- вводить пароли;
- покупать/оплачивать;
- отправлять сообщения от имени владельца;
- лазить в папки, требующие права администратора.

Даже если владелец хочет «всё сам», реализация должна оставлять confirm/dry-run для опасных действий.

## Важное про Q/A-корпус владельца

Корпус владельца — русский вопрос-ответ без мата. Это хороший формат для
обучения живого диалога. `steps/step_00_prepare.py` специально группирует
диалоги с маркерами `Пользователь:`, `Вопрос:`, `Агент:`, `Ответ:` в один
учебный блок, чтобы вопрос и ответ не разлетались по разным shard.

Лучший формат txt:

```text
Пользователь: вопрос
Агент: хороший ответ
Пользователь: следующий вопрос
Агент: следующий ответ
```

или одна пара в одной строке:

```text
Пользователь: вопрос. Агент: хороший ответ.
```

Если в файлах просто чередуются строки без маркеров (`вопрос` / `ответ`), лучше
перед следующим большим прогоном добавить маркеры, иначе модель хуже поймёт, где
вопрос, а где ответ.

## Данные

Разрешены источники:

- `Imperius/ru-classic` с HuggingFace;
- книги владельца с Google Drive;
- кодовые репозитории/архивы.

Свежие данные после 2019 года особенно нужны по программированию. Для фактов и новостей позже добавляется web-инструмент с источниками.

## Первый реальный прогон в GitHub Actions

Workflow: **«Дообучение в Actions»**.

Рекомендуемые inputs:

```text
data_source: hf
hf_dataset: Imperius/ru-classic
data_limit_mb: 25
start_step: 1
end_step: 2
max_steps: 300
```

Успех первого прогона:

- есть `checkpoints/step_01/last.pt`;
- есть `logs/progress.svg`;
- loss падает;
- `logs/eval_answers.md` показывает, что модель генерирует русский текст.

## Оценка качества

Промпты для ручной оценки лежат в `eval/model_quality_prompts.yaml`.
После обучения workflow запускает:

```bash
python scripts/evaluate_prompts.py --limit 12 --out logs/eval_answers.md
```

Плохой ответ:

- врёт;
- пишет не по-русски;
- не понимает Minecraft;
- не признаёт ошибку.

## UI на будущее

Цель — простое desktop-приложение: современный чат, бирюзовая тема, переключатели функций модели, значок `⏻`.
