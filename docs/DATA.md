# Данные для дообучения

## Получение корпуса Imperius/ru-classic (русская классика)

Ты прислал код через Croissant. Я сделал готовый скачиватель на ноут:

```bash
python3 scripts/download_ru_classic.py --limit-mb 20   # быстрый тест (20 МБ)
python3 scripts/download_ru_classic.py                 # весь корпус (~866 МБ)
python3 scripts/download_ru_classic.py --source croissant   # через mlcroissant
```

Стриминг: строки пишутся в `data/raw/text/ru_classic_000.txt` и далее кусками по
50 МБ — 16 ГБ RAM не переполняется. Подробности корпуса: 61 автор (Чехов, Толстой,
Достоевский, Гоголь, Блок…), публичное достояние, 6.9 млн строк, колонка `text`.

## Откуда взять ещё (на твоём ноуте, с интернетом)

1. **ruGPT-3 сам по себе — офлайн-заготовка**: после первого запуска
   `steps/step_00_prepare.py` токенизатор скачается в кэш HF, дальше сеть не нужна.
2. **Книги (общественное достояние)**: Викитека, Гутенберг, litres — формат `.txt`/`.epub`.
3. **Википедия**: дампы *текста* страниц (`ruwiki-...-pages-articles.xml.bz2`),
   очистка — `wikiextractor`.
4. **Диалоги**: свои чаты (самый ценный домен для «характера»), выгрузил — положи в `data/raw/text/`.
5. **Код C/C++/C#**: свои проекты, открытые репозитории (`.c`, `.cpp`, `.cs` слить в тексты в `data/raw/code/`).

## Формат

- `data/raw/text/` — любой `.txt` (по строке = фраза/абзац);
- `data/raw/math/` — вопросы + ответы с решениями;
- `data/raw/code/` — код с комментариями;
- `data/raw/behavior/` — «не обзываться»: диалоги вежливого поведения.

`steps/step_00_prepare.py` сам раскладывает: text → порции 1–4, math → 5–6,
code → 7–8, behavior → 9–10.

## Быстрая подготовка

```bash
# 1) демо-корпус (полностью офлайн, синтетика):
python3 scripts/make_data.py
# 2) любые свои .txt одним махом:
mkdir data/bag && cp /*.txt data/bag/ && python3 scripts/make_bag.py
# 3) токенизация в 10 порций:
python3 steps/step_00_prepare.py
# 4) обучение (на ноуте, GPU 1):
python3 orchestrator.py --start 1 --end 10 --device cuda --gpu auto --evaluate
```

## Объёмы (ориентир для RTX 3060)

- **Тест**: 5–10 МБ — прогон за минуты, ловим ошибки пайплайна.
- **Минимально полезно**: 100–200 МБ (~30–60 млн токенов) — модель реально
  начинает перенимать стиль; 1 эпоха ≈ 2–4 ч.
- **Хорошо**: 1–2 ГБ — заметное поведение; готовься к прогонам в несколько заходов.
