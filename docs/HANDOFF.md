## 1. Что за проект

Две связанные вещи в одном репозитории:

1. **Пайплайн дообучения русской языковой модели** — `ruGPT-3 Small` (125M,
   `ai-forever/rugpt3small_based_on_gpt2`). Обучение идёт **на ноуте**
   (Gigabyte G5 KD, реальная карта — RTX 3060 Laptop 6 ГБ), GitHub Actions
   работает дирижёром: шаги, чекпоинты, график loss, Job Summary.
2. **ПК-агент** (`agent/`) — надстройка над обученными моделями: роутер
   разводит запросы по экспертам (чат / код / математика / зрение),
   плюс инструменты для файлов и команд в песочнице и память.

Третьим куском в `main` живёт проект **«Глаза для UE5»**: свёрточная сеть
учится видеть редактор Unreal Engine 5 — панели, режим редактора, иконки
тулбара. Кадры генерируются кодом, но из **подлинных ассетов Epic** (цвета из
`StyleColors.cpp`, иконки из `Engine/Content/Slate/Starship/**`), иначе агент
выучит интерфейс, которого не существует.

Сквозная идея: **не одна большая модель на всё**, а несколько отдельно
обученных способностей со своим переключателем.

## 5. Блокеры и известные проблемы

1. **`Train + Progress` висит в очереди.** При запуске по `push` в workflow
   нет `github.event.inputs.runner`, поэтому `runs-on` падает в дефолт
   `self-hosted`. Self-hosted раннер на ноуте не зарегистрирован → задача
   стоит в очереди до таймаута (350 мин) и жжёт лимит.
   *Лечение (не сделано):* для событий `push` брать `ubuntu-latest` с
   коротким `max_steps`, а `self-hosted` оставить только для ручного запуска.
2. **Данных для обучения нет.** `data/raw/` пуст: корпус (Imperius/ru-classic,
   ~866 МБ, 61 автор) качается на ноуте командой
   `python3 scripts/download_ru_classic.py`, в git его не кладём.
3. **Обучение на ноуте ещё ни разу не запускалось** — нет ни чекпоинтов, ни
   `logs/*.jsonl`. То есть все отчёты о loss пока синтетические/CI-шные.
4. **Self-hosted раннер не настроен.** Вариант B из
   `docs/SELF_HOSTED_RUNNER.md` (прогресс в интерфейсе Actions) не начат.
5. **Эксперт «код» — заглушка**, домена C/C++/C# в данных ещё нет.
6. **Веса «глаз» UE5 не обучены**: ручной прогон был отменён на 11-й минуте.
7. **В песочнице агента нет torch** — тесты локально не гоняются, только в CI.

## 8. Решения и инварианты (не ломать без причины)

- **Учим на ноуте, Actions дирижирует.** Бесплатный раннер — CPU, без GPU;
  GPU-раннеры GitHub платные. Ноут: i5-11400H (5 потоков на данные, 1 — тебе),
  RTX 3060 Laptop 6 ГБ, 16 ГБ RAM. Эпохи — по 2–3 за заход с резюмом,
  суммарно 20–30: иначе перегрев и потеря прогресса при сбое.
  Ориентир: порция 100 МБ ≈ 25–35 млн токенов ≈ 2–3 ч на эпоху.
- **Ловушка нумерации GPU.** В Windows «GPU 1» = RTX 3060, но у CUDA-индексов
  Intel UHD не существует, поэтому RTX 3060 — это индекс **0**. `--gpu auto`
  это разруливает сам; iGPU не трогаем никогда.
- **Только подлинные ассеты Epic для «глаз».** Цвета и иконки не подбираем на
  глаз: обучение на выдуманном интерфейсе уже провернули на соседнем проекте —
  на реальном скриншоте модель выдавала уверенную чушь. Ассеты Epic в
  репозитории не хранятся, их качает `tools/fetch_ue5_assets.py`.
- **Зрение — отдельная модель.** «Глаза» не зашиваются в текстовую модель;
  2D сейчас, 3D (`kind: depth`) — когда появится датасет.
- **Управление ПК — это код, а не обучение.** Инструменты (tool-calling)
  работают поверх обученной текстовой модели; песочница по умолчанию,
  `dry_run` — лучший режим для проверки.
- **Тяжёлое в git не кладём:** `data/raw`, `data/shards`, `checkpoints`,
  `logs`, `models`, `assets/ue5/`, память агента — всё в `.gitignore`,
  папки держатся на `.gitkeep`.
