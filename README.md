# AI-Learning

Пайплайн дообучения русской языковой модели (ruGPT-3 Small) с прогрессом
в GitHub Actions. Обучение ведётся на локальном GPU (ноут Gigabyte G5 KD,
RTX 3060 = GPU 1), Actions — дирижёр: шаги, чекпоинты, отчёт о прогрессе.

## Дорожная карта

| Этап | Что | Где |
| --- | --- | --- |
| 0 | Сбор и чистка русского текста | `data/raw/*.txt` |
| 1 | Токенизация → 10 порций | `steps/step_00_prepare.py` |
| 2 | Обучение порций 1..10 (резюме с чекпоинта) | `steps/step_01.py … step_10.py` |
| 3 | Сводный отчёт + график loss | `steps/step_11_evaluate.py` |
| 4 | Автоматизация и прогресс | `.github/workflows/train.yml` |

Домены в данных:
- **Русский текст / диалоги** — база и разговор (порции 1..4);
- **Математика** — арифметика, выражения, задачи (порции 5..6);
- **Код C / C++ / C#** — синтаксис и паттерны (порции 7..8);
- **Поведение / инструкции** — вежливость, следование просьбам, отсутствие обзывательств (порции 9..10).

## Быстрый старт (ноут, GPU 1)

```bash
pip install -r requirements.txt
pip install torch --index-url https://download.pytorch.org/whl/cu121

# положи .txt в data/raw/
python steps/step_00_prepare.py
python orchestrator.py --start 1 --end 10 --device cuda --gpu 1 --evaluate
```

## Структура

```
├── config/train.yaml        # модель, гиперпараметры, пути
├── src/                     # ядро: config, данные, тренер
├── steps/                   # шаги 00..11
├── orchestrator.py          # запускает диапазон шагов
├── data/raw/                # сюда класть .txt (не в git)
├── data/shards/             # токенизированные порции (не в git)
├── checkpoints/             # чекпоинты по шагам (не в git)
├── logs/                    # JSONL-журналы + progress.svg (не в git)
└── .github/workflows/       # Actions: запуск + прогресс
```

## Прогресс

Каждый шаг пишет `logs/step_NN.jsonl` (loss, lr, токен/с, время).
`step_11_evaluate.py` собирает всё в таблицу и `logs/progress.svg`.
В GitHub Actions всё дублируется в Job Summary + артефакт `training-progress`.

## Важные решения (см. docs/SELF_HOSTED_RUNNER.md)

- GPU-обучение — на ноуте (RTX 3060, `CUDA_VISIBLE_DEVICES=1`); GitHub бесплатный
  CPU-раннер для реального обучения не хватает.
- Эпохи: по 2–3 за запуск с резюме, суммарно до 20–30 (иначе перегрев и риск сбоя).
- Зрение «глаз» (распознавание сред, напр. Unreal Engine) — **отдельная** vision-модель:
  она не «зашивается» в текстовую; её добавлю, когда пришлёшь файл/датасет.
- Управление ПК по просьбе — **агент с инструментами** (tool-calling) поверх
  обученной текстовой модели: это код, а не обучение; добавляется сверху.
