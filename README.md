# Глаза для интерфейса Unreal Engine 5

Модель учится **видеть редактор UE5**: где вьюпорт, Outliner, Details и
Content Browser, в каком режиме находится редактор и какие иконки лежат на
панели инструментов.

## Главный принцип: только подлинные ассеты Epic

Кадры собираются кодом, но материал в них настоящий:

| что | откуда |
|---|---|
| цвета темы | `Engine/Source/Runtime/SlateCore/Private/Styling/StyleColors.cpp` |
| иконки | `Engine/Content/Slate/Starship/**/*.svg` — 242 файла |
| раскладка | стандартная схема окна редактора |

Подбирать цвета на глаз и рисовать «похожие» значки нельзя: агент выучит
интерфейс, которого не существует. Это уже проверено на соседнем проекте —
модель, обученная на выдуманных текстурах, на реальном скриншоте выдавала
уверенную чушь.

Ассеты Epic **не хранятся** в репозитории. Их скачивает команда:

```bash
python3 tools/fetch_ue5_assets.py
```

## Запуск

```bash
pip install -r requirements.txt
python3 tools/fetch_ue5_assets.py          # 662 файла, 3.8 МБ
python3 pretrain_ui.py --samples 12000 --epochs 25 --eval-every 5
```

Быстрая проверка, что всё живо:

```bash
python3 pretrain_ui.py --samples 300 --epochs 3 --width 320 --height 180
python3 -m pytest tests/ -q
```

## Чему учится модель

Общий свёрточный энкодер и три головы:

1. **Координаты панелей** — 6 коробок: viewport, outliner, details,
   content, toolbar, statusbar. Выход в долях кадра.
2. **Состояние редактора** — режим (`edit` / `play` / `simulate` /
   `paused`) и есть ли выделенный объект.
3. **Иконки** — какие из 40 пиктограмм Starship присутствуют на панели.

Энкодер тот же, что обкатан в Mine-AI: `Conv(3→32,8,s4) → Conv(32→64,4,s2)
→ Conv(64→64,3,s1) → Conv(64→64,3,s2) → Conv(64→32,1)`. На 640×360 это
12.4 млн параметров.

## Качество кадра

Кадр должен быть похож на настоящий снимок экрана, иначе сеть выучит
идеальные прямоугольники. Эталон замерен на реальных скриншотах редактора,
приведённых к 640×360:

| | детализация | цветов |
|---|---|---|
| настоящие скриншоты UE5 | 4.11 – 6.83 | 7 882 – 18 860 |
| **наш рендер** | **4.18** | **19 276** |
| голая отрисовка (было) | 3.81 | 261 |

Разница между «было» и «стало» — субпиксельное сглаживание, неравномерность
подсветки и слабый шум матрицы. Тест `test_frame_quality_matches_real_screenshots`
не даёт вернуться к плоским заливкам.

## Тесты

```bash
python3 -m pytest tests/ -q      # 12 passed
```

Главное, что они стерегут:

- цвета совпадают с `StyleColors.cpp` до байта;
- все пути иконок существуют (половина «очевидных» имён в UE5 не такая,
  какой кажется);
- разметка совпадает с картинкой — проверка по цвету пикселей внутри
  коробок;
- панели не перекрывают друг друга;
- кадр не скатывается в плоские заливки.
